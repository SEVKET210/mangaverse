# MangaVerse 📖✨

> Sıfırdan tasarlanmış, yüksek performanslı Türkçe manga, manhwa ve webtoon okuma platformu.

---

## 🌟 Özellikler

- 📖 **Gelişmiş Okuma Modları**: Sayfalı ve dikey (webtoon) modları, son okunan yeri otomatik kaydetme.
- 🔍 **Katalog & Keşif**: Tür, yayın durumu, popülerlik ve puanlama filtreleriyle zengin arama.
- 🏆 **Oyunlaştırma (Gamification)**: Kullanıcı seviyeleri (XP), unvanlar ve başarım rozetleri.
- 📚 **Kişisel Kütüphane**: Okunuyor, Tamamlandı, Bırakıldı ve Planlanan listeleri.
- 🛡️ **Yönetim Paneli (Admin)**: Manga, bölüm ekleme/düzenleme, kullanıcı rolleri ve yorum moderasyonu.
- 🎨 **Çeviri Stüdyosu & Loncalar**: Çevirmen ve editör ekiplerinin organize olabileceği alan.
- ⚡ **PWA Desteği**: Hızlı önbellekleme ve mobil cihazlara yüklenebilir uygulama deneyimi.

---

## 🚀 Hızlı Başlangıç

### Gereksinimler
- [Node.js](https://nodejs.org/) (v16 veya üzeri)

### Kurulum

1. Depoyu klonlayın:
```bash
git clone https://github.com/SEVKET210/mangaverse.git
cd mangaverse
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Sunucuyu başlatın:
```bash
npm start
```

Sunucu varsayılan olarak `http://localhost:3000` adresinde çalışacaktır.

---

## 🛠️ Teknolojiler

- **Backend**: Node.js, Express.js, Helmet, Compression, LRU Cache
- **Frontend**: Vanilla JavaScript, CSS3 (Modern Responsive UI), PWA (Service Worker)
- **Veri Depolama**: JSON tabanlı mock database
